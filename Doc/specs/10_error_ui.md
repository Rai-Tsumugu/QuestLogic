# 10_error_ui.md

## 概要
エラー発生時のUI表示とメッセージング仕様。
*   **Title**: エラー内容とエラーコード
*   **Message**: エラーの詳細

## 1. 子供向けエラー (RPG Style)

### ケース別UI
#### 1.1 ネットワーク切断 (Network Error)
*   **Title**: 「接続エラー」
*   **Message**: 「ネットワーク接続を確認してください。」

#### 1.2 カメラ権限なし (Permission Denied)
*   **Title**: 「カメラのアクセス権限無し」
*   **Message**: 「スマホの設定からカメラの許可をしよう。」

#### 1.3 サーバーエラー (500)
*   **Title**: 「サーバーエラー」
*   **Message**: 「情報を取得できませんでした。」

#### 1.4 バリデーションエラー (Input Error)
*   **PIN間違い**: 「コードが違います。」

## 2. 親向けエラー (System Style)
